Your data lives on this device

No login, account, tracking or cloud database. Training records are automatically saved to this browser's local storage, scoped to this webpage's address. The same dashboard opened in a different browser/device will have a different data set.

Important: Local browser data can be lost if you clear website data, use private browsing or change devices. A local HTML file opened directly on an iPhone may not keep storage reliably. For dependable day-to-day use, publish this single file at a stable address (for example, GitHub Pages with your existing GitHub account), then add it to your Home Screen. Export a backup each Sunday.

Backup and restore

Exports include all training entries. Keep backups somewhere private, such as iCloud Drive.

How to install on iPhone

Once this file has a stable HTTPS web address, open it in Safari, choose Share → Add to Home Screen. Use that same Home Screen shortcut to keep your saved records together. You don't need Vercel or Supabase.
